Workspace preferences · saved to this browser

🎨 Appearance Font size, theme ▾

Font size

%

Drag the slider for the common range, or type any value 50–200% in the box. Scales every panel so text, controls, and window dimensions grow together.

Theme

Saved per browser. Doesn't sync to other players.

Window highlight

Adds an accent border + glow to whichever window has focus. Turn off for a flatter look — the focus state still tracks for z-index, just without the visual mark.

👁 Visibility Show / hide UI ▾

Uncheck anything you don't need on screen. The settings (⚙) and search (🔎) buttons stay so you can always get back here. Zoom still works via Ctrl+wheel and Ctrl±/0 even when the controls are hidden.

🛠 Behavior Search, windows ▾

Search reprints

Controls which versions appear in the search bar and tab counts.

Window snapping

When dragging or resizing, edges snap to nearby windows within 8 px.

👤 Identity Name, author color ▾

Lines you write in Session Notes are colored with this. Each browser has its own identity.
